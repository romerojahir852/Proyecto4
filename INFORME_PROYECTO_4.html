2. Objetivos del Proyecto

Objetivo General: Modelar, implementar y validar la estructura de datos dinámica de Lista Enlazada Simple (Single Linked List) para la gestión integral de reservas aéreas de 68 asientos del sistema AeroLista, garantizando la interoperabilidad con Flask y el cumplimiento del 100% (9/9) en la suite de pruebas unitarias.

Objetivos Específicos:

  • Implementar los 9 métodos fundamentales sin utilizar métodos prohibidos de listas de Python (list(), in, index, pop, sort, len()).
  • Garantizar el correcto recorrido canónico por punteros (actual = actual.next).
  • Controlar exhaustivamente los 4 casos de desenganche de nodos en la operación de eliminación.
  • Conectar la memoria dinámica de la lista con la capa de persistencia JSON y los endpoints REST de Flask.

3. Fundamentación Técnica y Arquitectura

Una lista enlazada simple está compuesta por vagones o nodos que se vinculan mediante punteros. Cada nodo almacena una referencia a un objeto Pasajero y una referencia al nodo sucesor (next):

head │ ▼ ┌──────────┬───┐ ┌──────────┬───┐ ┌──────────┬───┐ │ Pasajero │ o─┼───>│ Pasajero │ o─┼───>│ Pasajero │ o─┼───> None │ #1005 3C │ │ │ #1002 1A │ │ │ #1009 7D │ │ └──────────┴───┘ └──────────┴───┘ └──────────┴───┘ data next data next data next

4. Implementación de los 9 Métodos en lista_pasajeros.py

Los métodos codificados cumplen rigurosamente con los lineamientos del proyecto:

4.1 Métodos de Estado: esta_vacia() y longitud()

def esta_vacia(self):
    """Retorna True si no hay nodos en la lista; False si hay al menos uno."""
    return self.head is None

def longitud(self):
    """Retorna la cantidad de reservas en tiempo O(1)."""
    return self.cantidad

4.2 Método de Listado: listar()

def listar(self):
    """Retorna una list de Python con todos los Pasajeros en orden cronológico."""
    resultado = []
    actual = self.head
    while actual is not None:
        resultado.append(actual.data)
        actual = actual.next
    return resultado

4.3 Búsquedas Lineales: buscar(), buscar_por_asiento() y buscar_por_cedula()

def buscar(self, numero):
    actual = self.head
    while actual is not None:
        if actual.data.numero == numero:
            return actual.data
        actual = actual.next
    return None

def buscar_por_asiento(self, asiento):
    actual = self.head
    while actual is not None:
        if actual.data.asiento == asiento:
            return actual.data
        actual = actual.next
    return None

def buscar_por_cedula(self, cedula):
    actual = self.head
    while actual is not None:
        if actual.data.cedula == cedula:
            return actual.data
        actual = actual.next
    return None

4.4 Modificación In-Situ: modificar()

def modificar(self, numero, nuevo_nombre, nueva_edad, nuevo_asiento):
    pasajero = self.buscar(numero)
    if pasajero is not None:
        pasajero.nombre = nuevo_nombre
        pasajero.edad = nueva_edad
        pasajero.asiento = nuevo_asiento
        return True
    return False

4.5 Eliminación Quirúrgica: eliminar()

def eliminar(self, numero):
    # Caso A: Lista vacía
    if self.head is None:
        return None

    # Caso B: Eliminar la cabeza
    if self.head.data.numero == numero:
        eliminado = self.head.data
        self.head = self.head.next
        self.cantidad -= 1
        return eliminado

    # Casos C y D: Nodo intermedio, terminal o inexistente
    anterior = self.head
    actual = self.head.next
    while actual is not None:
        if actual.data.numero == numero:
            anterior.next = actual.next
            self.cantidad -= 1
            return actual.data
        anterior = actual
        actual = actual.next

    return None

4.6 Filtrado por Clase: filtrar_por_clase()

def filtrar_por_clase(self, clase):
    resultado = []
    actual = self.head
    while actual is not None:
        if actual.data.clase() == clase:
            resultado.append(actual.data)
        actual = actual.next
    return resultado

6. Conclusiones

  1. Las listas enlazadas simples optimizan la inserción y desasignación dinámica de memoria sin incurrir en realocaciones costosas en memoria contigua.
